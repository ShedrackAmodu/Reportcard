# User Stories for Scholar Project


## 1. Administrator
- **As an administrator**, I want to set up the institute profile, configure academic sessions and batches, and manage user roles so that the system reflects the school's structure and access permissions.
- **As an administrator**, I want to publish notices and articles on the dashboard, and manage subscribers so that information is communicated effectively to staff and students.
- **As an administrator**, I want to view system-wide reports (e.g., visitor statistics, user registrations) from the dashboard so I can monitor activity and performance.

## 2. Academic Officer
- **As an academic officer**, I want to create departments, subjects, semesters, and subject groups so that the curriculum is organised and ready for student enrolment.
- **As an academic officer**, I want to access the counsel and admissions dashboard to review applications and progress admitting new students.
- **As an academic officer**, I want to assign teachers to subjects and batches, and upload academic notices, ensuring classes run smoothly.

## 3. Teacher
- **As a teacher**, I want to log in and access my assigned classes and student lists so I can enter grades, attendance, and communicate with students.
- **As a teacher**, I want to view published notices and articles relevant to faculty to stay informed about school events and policies.

## 4. Student / Applicant
- **As a prospective student**, I want to fill out and submit an online admission form with personal details and supporting documents so I can apply to the school.
- **As a student**, I want to log in to view my profile, academic records, and download notices relevant to my classes.
- **As a student**, I want to make payments (e.g., admission fee, tuition) through the online payment page.

## 5. Parent / Guardian
- **As a parent**, I want to create or access an account linked to my child's profile so I can monitor their academic progress and receive notices.
- **As a parent**, I want to view published notices, pay fees, and contact the school through the portal.

## 6. General Visitor
- **As a visitor**, I want to view the school's landing page, read blog articles, and browse notices without logging in.
- **As a visitor**, I want to contact the school or sign up for updates via the  site.
